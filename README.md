# hohperformance

Website for HOH Performance (Treybuilt): K-swaps, B-swaps, custom wiring, diagnostics, tunes, and merch.

Static site, no build step. Open `index.html` or serve the folder with any static host.

- `index.html` – the full site (inline CSS/JS)
- `assets/` – images, YouTube thumbnails, favicon, OG image
- `merch-print/` – 3000px transparent print files (logo, white mono logo, hoodie back)
